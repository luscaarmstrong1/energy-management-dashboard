# Descrição de Portfólio

Desenvolvimento de uma plataforma analítica para gestão energética com base sintética de 315.360 medições horárias distribuídas entre 6 unidades fictícias. O projeto integra consumo, demanda, custos, geração fotovoltaica, intensidade energética, baseline, oportunidades de eficiência e detecção estatística de anomalias, usando Python, Streamlit e modelagem preparada para Power BI.
