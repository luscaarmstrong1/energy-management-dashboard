# Post LinkedIn

Transformar medições de energia em decisões de engenharia exige mais do que gráficos de consumo.

Criei o Dashboard de Gestão e Analytics de Energia, um projeto de portfólio com 315.360 medições horárias sintéticas distribuídas entre 6 unidades fictícias. A solução analisa consumo, demanda máxima, demanda contratada, custos, horário de ponta, geração fotovoltaica, autoconsumo, emissões evitadas, baseline, intensidade energética, oportunidades de eficiência e anomalias.

O projeto combina Python para geração, tratamento e validação dos dados, Streamlit para demonstração web e uma estrutura preparada para Power BI com modelo estrela, DAX, Power Query e tema visual.

Alguns resultados do case:
- Consumo total: 51.076,0 MWh
- Custo total sintético: R$ 54.690.956,73
- Geração solar: 2.601,0 MWh
- Cobertura solar: 5,1%
- Economia potencial identificada: R$ 7.075.714,72/ano
- Anomalias detectadas: 562

O principal aprendizado foi conectar indicadores técnicos como kW, kWh, kWp, fator de carga, fator de potência e autoconsumo a uma narrativa de decisão: onde agir, por quê e com qual impacto esperado.
